# Anantah Space Intelligence MFE

Responsive conversational interface connected to the Python Intelligence bootstrap service.

## Local dev

```powershell
npm install
npm run dev
```

Runs on `http://localhost:4177`.

Start the Python service separately:

```powershell
cd C:\ANANTAH\microservices\src\Anantah.Space.Intelligence.Agent
py app.py
```
