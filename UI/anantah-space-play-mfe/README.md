# Anantah Space Play MFE

Responsive game-library portal for featured titles, categories, player profiles, and future playable browser games.

## Local dev

```powershell
npm install
npm run dev
```

Runs on `http://localhost:4178`.

## Recommended game engine

Use Phaser for the first playable 2D browser game. Phaser is free and open source, but it has not been installed because dependency approval was unavailable. After approval, add it only to this MFE:

```powershell
cd C:\ANANTAH\UI\anantah-space-play-mfe
npm install phaser
```

Use Unity later only for larger 3D or C#-centric games; it is not needed for the current portal.
